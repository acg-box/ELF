# Benchmark recovery

The registered recovery conditions have ended. All four scale-1000 targets now
have ten native queries and ten reader answers in separate recovery conditions:
ELF has ten correct answers, Hindsight nine, SAG eight, and Mem0 seven.
GraphRAG still has measured native lifecycle failures. Original campaign results
and failures remain unchanged. These fixed workloads do not establish a general
product ranking.

## Conditions and boundaries

The original campaign uses zero gateway retries. These independent recovery
conditions permit up to three extra attempts after an explicit embedding HTTP
429. Each attempt reserves budget. Other transport failures do not trigger
replay by that gateway policy. Native clients can have separate retry policies.
Unknown charges remain reserved.

The alternate embedding route uses Qwen3 Embedding 8B through Nebius with 1,536
dimensions and no provider fallback. Chat uses DeepSeek V4.1 Flash through
DeepSeek with low reasoning. Preserve provider differences when comparing
results. The `conditions.json` records the exact source, image, workload, oracle,
and provider identities for each attempt.

Scale recovery allows 14,400 seconds for ingestion and 18,000 seconds for native
execution. These deadlines do not erase original timeouts. ELF's 220-character
fragments produce more notes than source records. Source receipts alone do not
prove query coverage.

The early Team Infisical read failed with HTTP 403. Personal Infisical resolved
the migrated credential mapping. The retained access-blocker receipt describes
a historical failure, not a current blocker. No secret values are exported.

### SAG

The v3 attempt completed 512 sources before extraction rolled back after
embedding transport failures. The v4 continuation copied retained state and
used native `replace_current` for the first incomplete source. It reached 531
sources before indexing rolled back after two more transport failures. Both
attempts produced no query results. Their errors and uncertain charges remain.

The adapter had reduced embedding retries to one, below the pinned native
library default of three. The separate v5 continuation uses the native default
without changing models, image, workload, or queries. It retained the original
531-source prefix and completed all 1,000 sources. Read-only checks found all
1,000 chunks and 1,118 events in SQL and vector storage, with no missing or extra
records. All ten native queries and reader answers completed; eight were correct.

Cases 010 and 011 missed the facts for Aster-0000 and Aster-0009. Retrieval
returned other services, and the reader returned `unknown`. Six correct answers
also had explicitly rejected development alternatives in their contexts. These
